================================================================
ARDUINO IDE 2.x - Board Settings voor Amiga Floppy Emulator
================================================================

1. BOARD MANAGER
   - Open: Tools → Board → Board Manager
   - Zoek: "esp32" door Espressif Systems
   - Installeer versie 2.0.x (NIET 3.x, die heeft breaking API changes)

2. BOARD SELECTIE
   - Tools → Board → ESP32S3 Dev Module

3. BOARD SETTINGS (Tools menu)
   - Board:              ESP32S3 Dev Module
   - USB CDC On Boot:    Enabled
   - USB Mode:           Hardware CDC and JTAG
   - Flash Size:         8MB (64Mb)
   - Partition Scheme:   8M with spiffs (3MB APP/1.5MB SPIFFS)
   - PSRAM:              OPI PSRAM
   - Upload Speed:       921600
   - CPU Frequency:      240MHz (WiFi)

4. POORT
   - Selecteer de COM-poort van je ESP32-S3

5. EERSTE UPLOAD
   - Houd de BOOT knop ingedrukt op de ESP32-S3
   - Klik Upload in Arduino IDE
   - Laat BOOT los zodra "Connecting..." verschijnt

6. SERIAL MONITOR
   - Tools → Serial Monitor
   - Baudrate: 115200
   - Je ziet de MFM self-test resultaten en WiFi status

7. GEBRUIK
   - Verbind je telefoon met WiFi "AmigaFloppy" (ww: amiga1200)
   - Open http://192.168.4.1
   - Upload een .ADF bestand
   - Verbind de ESP32 met de Amiga floppy poort
